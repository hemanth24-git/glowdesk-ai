# GlowDesk AI — AI Front Desk Automation Suite

An 11-workflow AI automation suite built for salons, spas, and clinics — designed to handle the entire front desk on autopilot.

**Live demo:** [https://index1-inky-seven.vercel.app/](https://index1-inky-seven.vercel.app/)

## What it does

GlowDesk AI replaces manual front-desk work with automated, always-on systems:

- **WhatsApp AI Receptionist** — handles client enquiries and bookings in real time
- **Voice AI** — phone-based booking and query handling
- **Appointment Booking** — confirms bookings instantly, no back-and-forth
- **No-Show Reduction** — automated reminders to cut missed appointments
- **Missed-Call Recovery** — follows up automatically on unanswered calls
- **Lead Follow-Up** — nurtures new enquiries until they convert
- **Client Reactivation** — re-engages past clients automatically
- **Review Monitoring + Auto-Drafted Replies** — tracks Google reviews and drafts responses
- **Live Analytics Dashboard** — real-time visibility into bookings and performance

## Tech stack

n8n · Twilio · Vapi.ai (Voice AI) · GPT-4o · RAG/Vector Search · Google Sheets/Calendar · Apify
